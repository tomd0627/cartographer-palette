How It Works

1. Seeded Randomness

Every map begins with a seed — an 8-character hexadecimal string that fully determines everything you see. The seed is converted to a 32-bit integer via the FNV-1a hash, then fed into a Mulberry32 pseudo-random number generator. The same seed always produces the same map, on any device, in any browser.

2. Height Field (FBM)

A height value is assigned to every point on an 800×550 grid using Fractional Brownian Motion — six layers of Simplex noise at increasing frequencies and decreasing amplitudes. Early octaves define the continental shape; later octaves add ridges and textural roughness.

3. Island Mask

Raw noise wraps continuously with no edges. A radial falloff function forces points near the canvas border toward sea level, creating a surrounded-by-ocean island. The falloff boundary is perturbed by a second noise pass so no two coastlines share the same silhouette.

4. Terrain Classification

Each point's final height is mapped to one of seven terrain tiers by threshold: deep ocean, shallow water, coastline, lowland, highland, mountain, and snow peaks. A subtle brightness shift within each tier adds dimensionality without relying on external textures.

5. Organic Coastlines

After terrain colors are written to an off-screen pixel buffer, a 3×3 box-blur pass is applied once. This softens hard boundaries between terrain types, producing the graduated transitions that read as genuine geographic detail rather than aliased pixel edges.

6. Cartographic Finish

A radial vignette deepens the map's edges. A double-rule border, compass rose, and parchment gradient are composited on top using the Canvas 2D API directly — no SVG, no image assets. The entire pipeline runs in under 100 ms on a mid-range device.
